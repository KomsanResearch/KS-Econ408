# KS Econ408 Web
Your Ambition, Your Pathway.

Static web version of the KS Econ408 V1.4 adaptive achievement pathway, based on the original Python logic and `questions.json`.

Files: `index.html`, `app.js`, `questions.json`.

This version does not store student answers on a server. Questions and branches are visible to anyone who can access the website; do not use this static version for a secure graded examination.
